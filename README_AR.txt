هيمنة الفريق - نسخة لعب تجريبية قابلة للتطوير

ابدأ من index.html عبر خادم HTTP أو GitHub Pages. يحتاج اتصالاً بالإنترنت لتحميل Three.js من CDN.

الموجود في هذه النسخة: تحميل الجندي GLB تلقائياً، اختيار وتحميل الخرائط GLB، كاميرا منظور ثالث، عصا حركة لمس، سحب لتدوير الكاميرا، قفز/جثوم/انبطاح/ميل، إطلاق نار وتلقيم وتبديل أسلحة، بوتات تدريب أولية، إعدادات حساسية وحجم وشفافية الأزرار.

تنبيه: هذه نسخة أولية قابلة للعب وليست لعبة بمستوى PUBG. البوتات والضرر والرسوميات وأنيميشن الحركة تحتاج اختباراً وضبطاً. اللعب الجماعي الحقيقي عبر Wi-Fi غير منفذ في هذه النسخة ويتطلب خادماً منفصلاً واتصال WebSocket.
